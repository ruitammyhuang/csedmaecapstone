Ed Tech Tool D&D: Develop MVP Due Friday (before meeting)

▾

Build a fully functional MVP with core features, test it with users, and refine based on feedback.

Tasks

Complete these tasks early so you have time to validate and refine your MVP.

  • Develop a functional MVP
    Develop a fully functional MVP (Minimum Viable Product) of the educational technology tool, including core features identified in previous phases.
  • Implement using an appropriate platform
    Utilize a programming language and platform such as HTML, JavaScript, Python, or others as appropriate.
  • Test with users
    Test the MVP with at least two stakeholders or target users to validate functionality and usability.
  • Document and refine
    Document feedback from testing sessions and identify areas for final refinements.
Deliverables

Submit by Friday so the instructor can review and provide formative feedback before we meet.

  • MVP Report including:
    • A description of the MVP and its core features
    • Feedback and key insights from testing sessions
    • A summary of final refinements made based on feedback
    • A reflection on the MVP development process and lessons learned
  • Supporting documents:
    • Source code and documentation for the MVP
    • Images, screenshots, or videos demonstrating the tool in action
    • Notes or transcripts from testing sessions

Combine everything into one Google Doc (link supporting documents if needed) and submit a shareable link to this Google Spreadsheets file under the corresponding worksheet.

Make sure your Google doc allows your peers to leave comments.

Course D&D: Develop MVP Due Friday (before meeting)

▾

Fully implement two lessons, pilot test with learners, and refine based on evidence.

Tasks

Complete these tasks early so you can pilot test and polish your lesson implementation.

  • Implement two lessons
    Develop two fully implemented lessons for the course based on the module prototype from Sprint 3.
  • Include full lesson components
    Include all learning activities, assessments, and instructional materials necessary for these lessons.
  • Pilot test
    Conduct a pilot test of the lessons with at least two target learners.
  • Document and improve
    Document feedback from the pilot testing sessions and identify areas for improvement.

    • Lesson plans, slides, or other instructional materials used for the lessons

Teacher Inquiry Project: Analyze Data Due Friday (before meeting)

▾

Clean and analyze your collected data, identify findings, and connect results back to your wonder.

Tasks

Complete these tasks early so you have time to make your analysis clear and defensible.

  • Clean and organize data
    Organize and clean the collected data from Sprint 3.
  • Conduct analysis
    Conduct data analysis using appropriate qualitative or quantitative methods.
  • Identify findings
    Identify patterns, themes, or key findings from the data.
  • Summarize clearly
    Summarize the findings in a clear and concise manner.
Deliverables

Submit by Friday so the instructor can review and provide formative feedback before we meet.

  • Analysis Report including:
    • A description of the data analysis process
    • Key findings, patterns, or themes identified in the data
    • A discussion of how the findings address the wonder defined in Sprint 1
    • A reflection on the data analysis process and lessons learned
  • Supporting documents:
    • Data sets, charts, or visualizations created during the analysis process
    • Notes or transcripts used in the analysis
