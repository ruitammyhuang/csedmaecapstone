Sprint 3: Prototyping / Collect Data

Ed Tech Tool D&D: Prototyping

Tasks

  • Develop a functional prototype of the selected educational technology tool from Sprint 2.
  • Conduct usability and learner experience testing with at least two stakeholders or target users.
  • Document feedback from the testing sessions, highlighting key insights and areas for improvement.
  • Iterate on the prototype based on the feedback collected.

Deliverables

  • A Prototype Report including:
    • A description of the prototype and its functionality.
    • Key insights from usability and learner experience testing.
    • A summary of changes made to the prototype based on feedback.
    • A reflection on the testing process and lessons learned.
  • Supporting documents:
    • Images, screenshots, or videos of the prototype.
    • Notes or transcripts from testing sessions.

Please combine all required deliverables into one Google doc (add links to supporting documents if applicable), and then submit a sharable link to this discussion board. Make sure your peers can leave comments in your document.

Course D&D: Prototyping

Tasks

  • Develop a prototype for one module of the course based on the structural plan from Sprint 2.
  • Implement learning activities, assessments, and materials for the module.
  • Conduct a small-scale test of the module with at least two target learners.
  • Document feedback from the testing sessions, highlighting key insights and areas for improvement.
  • Revise the module prototype based on the feedback collected.

Deliverables

  • A Module Prototype Report including:
    • A description of the module prototype, including learning objectives, activities, and assessments.
    • Key insights from the testing sessions with target learners.
    • A summary of changes made to the module based on feedback.
    • A reflection on the testing process and lessons learned.
  • Supporting documents:
    • Links to or examples of module materials (e.g., lesson plans, slides, or assessments).
    • Notes or transcripts from testing sessions.

Please combine all required deliverables into one Google doc (add links to supporting documents if applicable), and then submit a sharable link to this discussion board. Make sure your peers can leave comments in your document.

Teacher Inquiry Projects: Collect Data

Tasks

  • Implement your data collection plan developed in Sprint 2.
  • Collect data using the selected methods (e.g., surveys, interviews, observations).
  • Ensure ethical practices are followed, including anonymizing and securing participant data.
  • Document the data collection process, including challenges faced and how they were addressed.

Deliverables

  • A Data Collection Summary including:
    • A description of the data collection process and methods used.
    • A summary of data collected, including key observations or preliminary findings.
    • A reflection on the data collection process, including challenges and lessons learned.
  • Supporting documents:
    • Completed surveys, interview transcripts, or observation notes (de-identified if applicable).
    • References to tools or instruments used for data collection.

Please combine all required deliverables into one Google doc (add links to supporting documents if applicable), and then submit a sharable link to this discussion board. Make sure your peers can leave comments in your document.
